# Assessments

Three ways to check what landed, in increasing order of how much they ask of you.

| Page | What it tests | Needs |
| --- | --- | --- |
| [Final exam](final-exam.md) | Reasoning across all seventeen steps — 17 step questions plus 3 anti-pattern scenarios, answer key behind one fold at the bottom. | Having read the course. |
| [Capstone rubric](capstone-rubric.md) | A finished [Project 8](../projects/08-wire-two-loops-together-capstone.md) submission, scored against seven criteria with two of them acting as gates. | Having built the capstone. |
| [Graph Ready certification](graph-ready-certification.md) | A real system, against the seven-item checklist. Pass is seven of seven. | Having shipped something. |

The exam and the rubric can be taken in either order. The certification is different in kind: it asks you to point at structures in a system that actually runs, and the honest answer for a system that does not yet exist is that it is not ready, rather than a lower score.
